# Laboratorios Chopo — Exámenes SSJ Antidoping

Sistema de validación de licencias y registro de resultados para Laboratorios Chopo.

## 🚀 Características
- Validación de folios y licencias
- Generación de códigos QR automáticos
- Base de datos local (no requiere servidor)
- Interfaz responsive

## 📦 Cómo usar
1. Descarga o clona este repositorio
2. Abre el archivo `index.html` en cualquier navegador
3. Ingresa el folio para validar
